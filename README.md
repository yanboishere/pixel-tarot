# ✦ 像素塔罗 · Pixel Tarot

一个像素风格的塔罗占卜网站：许下愿望（也可以跳过）→ 选择牌阵 → 洗牌 → 切牌 → 从 78 张牌中亲手抽牌 → 逐张翻开解读 → **穷举全部可能的抽牌结果，算出这件事成真的概率**。

纯静态页面，无需构建、无任何依赖，所有牌面都是在 canvas 上逐像素绘制的。

## 玩法

1. **许愿**：写下你想问的事。系统会识别问题领域（感情 / 事业 / 财富 / 学业 / 健康），与之同元素的牌影响加倍。不写则占卜近期整体运势。
2. **选牌阵**：单张指引（1 张）、时间之流（过去 / 现在 / 未来）、愿望之路（5 张）、凯尔特十字（10 张）。
3. **按塔罗仪式抽牌**：
   - 洗牌：用 `crypto.getRandomValues` 做无偏 Fisher–Yates 洗牌，洗牌时随机翻转部分牌，产生逆位；
   - 切牌：牌被分成三叠，凭直觉选一叠放到最上面；
   - 抽牌：78 张牌背面朝上展开，依次点选每个位置的牌。
4. **翻牌解读**：每张牌给出正 / 逆位关键词、牌义、所在位置的含义、元素与领域，最后给出综合解读。
5. **概率**：见下文。

## 概率是怎么算的

- 每张牌按传统牌义赋予吉凶值（-3 ~ +3），正位与逆位不同；与愿望同元素的花色正位 +1、逆位 -1。
- 牌阵各位置有权重（例如「未来 / 最终结果」权重最高），整组牌得分 = Σ 位置权重 × 牌值。
- 一次占卜共有 `78 × 77 × … × (79 − k) × 2^k` 种等可能结果——凯尔特十字有 **4,675,765,217,094,107,136,000** 种。
- 用「已占用位置子集 × 得分」的动态规划**精确统计全部结果的得分分布**（与逐一枚举等价，浏览器里不到 0.1 秒）。
- 事件成真概率 = 得分低于本次的结果占比 + 同分结果占比 / 2，限制在 1% ~ 99%。
- 结果页同时展示：全部结果数、本次得分与理论范围、随机一次占卜偏吉的概率、抽到完全相同牌面的概率，以及整体得分分布图。

`tests/verify.js` 会对单张和三张牌阵做 **365 万种结果的逐项暴力枚举**，验证动态规划的分布完全一致：

```bash
node tests/verify.js
```

> 塔罗是一面镜子。这里的概率来自牌面的符号模型，仅供娱乐与自我觉察。

## 本地运行

直接双击打开 `index.html` 即可；或者起一个本地服务：

```bash
node scripts/serve.js 8080   # 然后访问 http://127.0.0.1:8080
```

## 目录

```
index.html            页面结构
css/style.css         像素风样式
js/cards.js           78 张牌的牌义、关键词与吉凶值
js/sprites.js         像素牌面 / 牌背位图与绘制
js/probability.js     牌阵定义、主题识别、穷举概率模型
js/app.js             许愿 → 洗牌 → 切牌 → 抽牌 → 解读 的交互流程
tests/verify.js       数据校验 + 动态规划 vs 暴力枚举
fonts/                缝合像素字体（SIL OFL 1.1）
```
